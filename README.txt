# Buquê virtual para Hadassa 🌷

## Como abrir no VS Code

1. Extraia os arquivos.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html`.
4. Clique com o botão direito nele e use "Open with Live Server", se tiver a extensão Live Server.
5. Se não tiver, também pode simplesmente abrir o `index.html` no navegador.

## Arquivos

- `index.html` — estrutura do site.
- `style.css` — visual, flores e animações.
- `script.js` — interações e pétalas.

## Música

A música escolhida foi "From The Start", da Laufey.

O site não inclui uma cópia da música por questões de direitos autorais. Se você tiver autorização para usar um arquivo de áudio, coloque `from-the-start.mp3` na mesma pasta e siga o comentário dentro do `index.html`.

## GitHub Pages

Depois de testar:

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. No repositório, abra Settings > Pages.
4. Em "Build and deployment", escolha "Deploy from a branch".
5. Selecione a branch `main` e a pasta `/root`.
6. Salve e aguarde o GitHub gerar o link.
