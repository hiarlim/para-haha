BUQUÊ VIRTUAL — HADASSA

Site refeito do zero, com visual mais elegante e pensado para celular.

Arquivos:
- index.html
- style.css
- script.js
- images/ (4 fotos)

GITHUB PAGES:
1. Crie um repositório no GitHub.
2. Coloque TODOS estes arquivos no repositório, mantendo a pasta images.
3. Settings > Pages.
4. Em Source, escolha Deploy from a branch.
5. Branch: main | Folder: / (root).
6. Save.

IMPORTANTE:
Não apague nem renomeie a pasta images. As fotos são carregadas por caminhos relativos.
A música é "From The Start", da Laufey. O botão abre a música no YouTube; o site não incorpora o áudio diretamente.
