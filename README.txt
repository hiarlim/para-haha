GitHub Pages:
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta, incluindo a pasta images.
3. Vá em Settings > Pages.
4. Em Source, escolha "Deploy from a branch".
5. Branch: main / root.
6. Salve.

A música começa quando a pessoa toca em "Abrir meu presente", porque navegadores normalmente bloqueiam áudio automático.
