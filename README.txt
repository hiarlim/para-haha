SITE DA HADASSA — pronto para GitHub Pages.

1. Extraia o ZIP.
2. Envie index.html, style.css, script.js, README.txt e a pasta images para o repositório.
3. GitHub: Settings > Pages > Deploy from a branch > main > / (root) > Save.

As quatro fotos estão DENTRO de images e usam caminhos relativos, então não aparecem como imagem quebrada.
